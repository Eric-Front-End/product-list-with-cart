# Product List with Shopping Cart

This project is a front-end application that simulates a basic e-commerce product page. It features a list of products that can be added to a persistent shopping cart.

## 🚀 Live Demo

You can view the deployed project and test it live here:

**[View Demo](https://eric-front-end.github.io/product-list-with-cart/)**

## 📖 Project Description

This application was built to practice key JavaScript concepts, especially DOM manipulation and client-side state management. It dynamically loads product data (from a local source or mock API) and renders it onto the page. Users can browse items and add their desired products to a shopping cart, which updates in real-time.

### Core Features

* **Dynamic Product Listing:** Products are loaded and displayed on the page using JavaScript.
* **Shopping Cart Functionality:** Users can add items to a shopping cart.
* **Cart State Management:** The cart's contents persist as the user interacts with the page.
* **Interactive UI:** A cart modal or sidebar displays the items that have been added.
* **Responsive Design:** The layout for both the product grid and the cart is designed to be responsive for different screen sizes.

## 🛠️ Technologies Used

This project was built using core front-end technologies:

* **HTML5:** For the semantic structure of the product page and cart modal.
* **CSS3:** For all styling, including the product card layout (using Flexbox or CSS Grid) and the cart's appearance.
* **JavaScript (Vanilla JS):**
    * To fetch and render product data.
    * To handle all user events (e.g., "Add to Cart" clicks).
    * To manage the shopping cart's state (adding items, updating quantities, etc.).
    * To dynamically update the DOM to reflect the current state of the cart.

## 🏁 Getting Started

If you want to run this project on your local machine, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Eric-Front-End/product-list-with-cart.git](https://github.com/Eric-Front-End/product-list-with-cart.git)
    ```

2.  **Navigate to the directory:**
    ```bash
    cd product-list-with-cart
    ```

3.  **Open the project:**
    Simply open the `index.html` file in your preferred web browser.
